# K6

Run load-test scripts against a live Spring Boot sample (not a Spring module itself).

Catalog: [`samples/20-k6`](../../../samples/20-k6). Runbook:
[`samples/20-k6/README.md`](../../../samples/20-k6/README.md).

App-shaped scripts also live under some samples (for example
`samples/16-virtual-threads/src/test/k6`).

## Before you start

- Previous: [Cloud Config](../advanced/cloud-config.md) — `samples/19-cloud-config`
- Install k6 (steps below)
- Start a target API — usually [`08-restapi`](../../../samples/08-restapi/README.md) on **8080**
- Auth scripts need [`18-security`](../../../samples/18-security/README.md) with `SECURITY_USER_*`
- Time: ~20 minutes

## Why this exists

Unit tests do not tell you how an endpoint behaves under concurrent users. k6
drives HTTP from outside the JVM so you can measure latency and check status
codes while Spring Boot runs normally.

## What you will see

- k6 summary after a run (VUs, duration, HTTP stats)
- Scripts under `samples/20-k6/*.js` hitting URLs such as `/api/v1/users`

## Run

Install on Ubuntu/Debian:

```bash
curl -s https://dl.k6.io/key.gpg | gpg --dearmor | sudo tee /usr/share/keyrings/k6-archive-keyring.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/k6-archive-keyring.gpg] https://dl.k6.io/deb stable main" | sudo tee /etc/apt/sources.list.d/k6.list
sudo apt update && sudo apt install k6
```

Start a target (example):

```bash
cd samples/08-restapi
mvn spring-boot:run -Dspring-boot.run.profiles=development
```

## Try it

From the **tutorial repo root**, with the target still running:

```bash
k6 run samples/20-k6/03-simple-get.js
```

That script uses 10 VUs for 30s and calls `http://localhost:8080/api/v1/users`.

Expected: a k6 end-of-test summary (HTTP metrics). Prefer `03-simple-get.js` as
the first real run; `01-lifecycle.js` is a commented skeleton and is skipped on
purpose.

Checks example (expects body text for user `1`):

```bash
k6 run samples/20-k6/05-checks.js
```

Env-driven host (`08-environment-variables.js`):

```bash
k6 run -e MY_HOSTNAME=http://localhost:8080/api/v1/users samples/20-k6/08-environment-variables.js
```

Basic auth scripts (`11-basic-authentication.js`, `12-setup-auth.js`) need
`SECURITY_USER_USERNAME` and `SECURITY_USER_PASSWORD` against `18-security`
(`GET /api/v1/security/profile`).

## How the sample is shaped

| Path | Role |
| --- | --- |
| `samples/20-k6/*.js` | Standalone k6 scripts |
| `samples/20-k6/data/data.json` | Shared payload data for some scripts |
| `samples/16-virtual-threads/src/test/k6` | App-shaped virtual-thread load script |

## Tests

No `mvn test` here — k6 is the runner.

## Stop

Stop the Spring Boot target with `Ctrl+C`. k6 exits when the script finishes.
