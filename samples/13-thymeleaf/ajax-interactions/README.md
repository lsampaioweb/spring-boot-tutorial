# 13 — Thymeleaf ajax-interactions

Task list with fragment/fetch add and delete.

## Run

```bash
cd samples/13-thymeleaf/ajax-interactions
mvn spring-boot:run -Dspring-boot.run.profiles=development
```

Open `http://localhost:8080/tasks` and use the UI to add/delete rows.

## Tests

```bash
mvn test
```
